StudentDormitory · 运行说明
========================================


【怎么装】
----------------------------------------
1. 把 学生公寓管理系统.apk 传到 Android 手机
2. 点击安装
   ※ 若提示"禁止安装未知来源应用"，到 设置 → 安全 → 允许安装未知应用
3. 安装后桌面出现「基于android的学生公寓管理系统」图标

无需联网，无需注册服务器，安装即用。


【内置账号】
----------------------------------------
管理员：账号 admin    密码 123
  首次安装时由数据库自动创建

学生：需要自己在登录页点「注册」新建


【怎么玩（建议按这个顺序体验两种角色）】
----------------------------------------
【学生端】
  1. 注册一个学生账号并登录
  2. 首页可操作：查询消息 / 日常报修 / 评分查询 / 校园帮助
                 欠费查询 / 请假上报 / 出入打卡
  3. 「请假上报」填原因、选日期、提交，下方会列出自己提交过的记录和审批状态
  4. 「欠费查询」输入宿舍号（如 103），会按末位奇偶显示房型年费与欠费金额，
     点「立即支付」弹出收款码
  5. 「校园帮助」里有校园地图、垃圾分类、求助电话
  6. 底部「我的」可改头像、个人信息、密码

【管理员端】
  1. 退出登录，在登录页点「管理员登录」，用 admin / 123 登录
  2. 首页可管理：消息推送 / 寝室评分 / 请假报告 / 进出记录
                 消息记录 / 入住管理
  3. 「请假报告」里点「同意」或「驳回」（驳回需填原因），学生端会立刻看到状态变化
  4. 「消息记录」里点「处理」把报修标记为已修
  5. 底部「宿舍管理」可查看、编辑、长按删除学生
     ※ 删除学生会连带清掉他的报修/请假/进出记录（事务保证）


【说明】
----------------------------------------
这是一个纯本地单机应用，数据全部保存在手机本地数据库中。

⚠️ 一个固有边界：因为是单机的，"学生上报 → 管理员处理"
   这条流程只有在同一台设备上才成立 —— 学生用自己手机提交的请假，
   管理员在另一台手机上无法看到。这是单机架构决定的，不是 bug。


【运行环境】
----------------------------------------
最低支持 Android 5.0（API 21）
已在 Android 14（API 34，Pixel 5 模拟器）上完整测试通过


【技术信息】
----------------------------------------
语言：Java 8
存储：Room 2.4.3（9 张表，AppDatabase version 8，WAL 模式）
构建：Gradle 8.9 + AGP 8.7.3 + JDK 17
规模：71 个 Java 文件 / 约 7200 行
作品展示：https://github.com/golmind/StudentDormitory-Showcase


【已知问题】
----------------------------------------
（主动写出来反而加分）
- 缴费登记暂无管理员入口，pay 表目前只读不写，所以欠费查询默认显示"暂无欠费记录"
- 寝室评分页面未按寝室过滤，学生可见全校成绩
- Fragment 仍使用已废弃的 android.app.Fragment，未迁移到 AndroidX
- 数据库操作全部在主线程，数据量增大有 ANR 风险
- 密码明文存储，未做加盐哈希
- 暂无单元测试
